# Cat Invaders

A small, playable browser game inspired by classic Space Invaders, with the three supplied rat sprites split into individual PNGs and custom pixel-art cat invaders.

## Play
Open `index.html` in a modern browser. Keep the `assets` folder beside it.

- Move: Left/Right arrows or A/D
- Shoot: Space
- Pause: P
- Restart: Restart button
- On touchscreens: use the on-screen buttons

## Sprites
- `assets/rat_player_1.png` — original first rat sprite; used as the player
- `assets/rat_player_2.png`, `rat_player_3.png` — the other separated rat sprites
- `assets/cat_invader_1.png` through `cat_invader_3.png` — three cat invader variants

Everything runs locally; no libraries or server required.
