# Greenwich RP — Static site

Upload the contents of this folder directly to the `main` branch of your `livvcoll-jpg.github.io` repository. In the repository's **Settings → Pages**, select **Deploy from a branch**, choose `main`, and choose `/ (root)`.

There is no installation or build step. Edit the HTML files and `site.css` directly. Search the files for `ADD OFFICIAL LINK` before launch and replace those placeholders with your Roblox, Discord, and form URLs.
